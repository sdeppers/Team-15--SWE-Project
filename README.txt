The main file is src/tag.py
It can be executed using 

python tag.py 

in the command line, provided pygame 2.6.1 is installed,
and python version 3.13.7 is installed and active in the shell.
(If that version is installed but not active the command

pyenv shell 3.13.7

will set it to active in the current shell instance.

Soon I will make a script to automatically install all
dependencies to the virtual machine environment.

All this may change in the future as needed, this is just
how I had my system set up last time I used pygame.
